# `list__i` API Reference

All functions below are generated by the `List__i__declare()` / `List__i__define()` macros for a singly linked list of `int`.

## Types

- **`List__i`** — `typedef struct list__i *` (opaque pointer to the list struct)
- **`List_Node__i`** — `typedef struct list_node__i *` (pointer to a node)
- **`struct list_node__i`** — contains `next` (`struct list_node__i *`) and `value` (`int`)

## Functions

### `list__i_init`

```c
List__i list__i_init(void);
```

Allocates and returns a new list. Head is NULL, size is 0. Returns `NULL` on malloc failure. Caller owns the list and must pass it to `list__i_deinit`.

---

### `list__i_deinit`

```c
void list__i_deinit(struct list__i *self);
```

Frees every node in the list, then frees the list struct itself. Passing `NULL` is safe (no-op). After this call, `self` is a dangling pointer.

---

### `list__i_push`

```c
int list__i_push(struct list__i *self, int val);
```

Allocates a new node with `val` and inserts it **at the head**. Returns `0` on success, `1` on malloc failure (list is unchanged on failure). Increments `self->size`.

---

### `list__i_pop`

```c
void list__i_pop(struct list__i *self);
```

Removes the **head** node and frees it. Decrements `self->size`. **Undefined behaviour if the list is empty** — caller must guarantee `self->size > 0` before calling.

---

### `list__i_head`

```c
struct list_node__i **list__i_head(struct list__i *self);
```

Returns the address of `self->head` (a `struct list_node__i **`). This is the **position indicator** used by `insert`, `erase`, and `find`.

To traverse: dereference once to get the first node (`*head`), then use `&(*node)->next` to advance. To check end-of-list: compare `*pos == NULL`.

---

### `list__i_size`

```c
size_t list__i_size(struct list__i *self);
```

Returns `self->size` — the number of nodes currently in the list.

---

### `list__i_insert`

```c
int list__i_insert(struct list__i *self, struct list_node__i **pos,
                   const int *restrict first, size_t n);
```

Inserts `n` elements from array `first` **after** the node pointed to by `*pos`. On success, `*pos` is advanced to point past the inserted block (so the original `*pos->next` remains the logical "rest" of the list). Returns `0` on success.

**Error handling (return `1`):** if any `malloc` fails mid-insertion, all partially-inserted nodes are freed and the list is rolled back to its pre-call state. `*pos` is restored to the original next pointer.

**Key semantics:**
- `pos = list__i_head(list)` means "insert at head" (equivalent to a multi-element push in order).
- `pos = &(*last)->next` means "append after `last`" (insert at tail position).
- `n = 0` is a no-op (nothing inserted, returns 0).
- Does **not** update `*pos` on failure — only on success.

---

### `list__i_erase`

```c
void list__i_erase(struct list__i *self, struct list_node__i **pos, size_t n);
```

Removes and frees `n` nodes starting at `*pos`. After the call, `*pos` points to the node that followed the erased block (or NULL if end-of-list). Decrements `self->size` by `n`.

**Corner case:** `n = 0` is safe (no-op, `*pos` unchanged). Caller must ensure `n ≤` nodes remaining from `*pos` onward — **undefined behaviour if `n` exceeds available nodes**.

---

### `list__i_find`

```c
struct list_node__i **list__i_find(
    struct list_node__i **pos, int val,
    int (*cmp)(const void *, const void *));
```

Searches forward from `*pos` for a node whose `value` equals `val`. Returns a position indicator (`struct list_node__i **`) pointing to the first match, or `NULL` if not found.

- `cmp` is called as `cmp(&val, &node->value)`. If `cmp` is `NULL`, a built-in `memcmp`-based comparison is used (comparing `sizeof(int)` bytes).
- The returned position can be passed directly to `insert` or `erase`.

**To resume searching after a match:** call again with `pos = &(*result)->next`.
